# RegexLab

## Problem

Developers ask recurring questions about regex (top public signal: 'How can I validate an email address in JavaScript?') while existing tools for it are published as open-source projects.

## Target customer

developers and technical teams working with regex

## Verified demand evidence (public sources, observed)

- How can I validate an email address in JavaScript? (https://stackoverflow.com/questions/46155/how-can-i-validate-an-email-address-in-javascript)
- Regular expression to match a line that doesn&#39;t contain a word (https://stackoverflow.com/questions/406230/regular-expression-to-match-a-line-that-doesnt-contain-a-word)
- BurntSushi/ripgrep (https://github.com/BurntSushi/ripgrep)
- ziishaned/learn-regex (https://github.com/ziishaned/learn-regex)
- gskinner/regexr (https://github.com/gskinner/regexr)

## MVP scope

Build the smallest useful command-line or single-file web tool that solves the stated problem
without paid dependencies, external paid APIs, or accounts.

Requirements:

1. Runnable with Python 3 standard library or plain HTML/JavaScript only.
2. README.md with install, usage, and examples.
3. At least one automated test or self-check command.
4. No network calls to paid services. Public, free, unauthenticated access is allowed only if
   documented and optional.
5. No secrets, credentials, or personal data written to disk.
6. Price hint: ["$9 one-time", "$5/month", "free + paid pro"]

## Success metric

first_confirmed_payment

## Failure condition

zero confirmed payments before experiment deadline
